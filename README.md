# QuakeWatch – BDM project report

LaTeX source and compiled PDF (`main.pdf`) of the Big Data Management report.
Code repository: https://github.com/vibhor-5/quakewatch-bdm

Build: `tectonic main.tex` (or any LaTeX distribution: `pdflatex main.tex` twice).
Figures in `figures/` are screenshots from the running app/dashboard and charts generated from the same data.

Presentation: `QuakeWatch_Presentation.pptx` (13 slides, speaker notes included) and `QuakeWatch_Presentation.pdf` (PDF export).
